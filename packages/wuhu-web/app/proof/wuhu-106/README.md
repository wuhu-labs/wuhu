# Inference transcript browser proof

`proof.mjs` drives installed Chrome against the actual production SPA served by a Bazel-built Wuhu CLI on a scratch TLS port. It uses bounded HTTP fixture pages and cancellable SSE to exercise the real subscription parser, committed-entry fold, inference projection and production inspection flow. It does not alter live transcripts or add lab controls to product UI.

## Run

Build the CLI with `bazel build //packages/wuhu-core:wuhu` from the checkout root. In `packages/wuhu-web/app`, run `deno task gen-contract && deno task build`; copy `build/client` to `/tmp/wuhu106-proof/current-app`. Install `playwright-core` in that scratch directory and copy `proof.mjs` there. Copy the canonical `packages/wuhu-core/Targets/SpaceContract/Tests/contract/transcript-semantics.json` to the scratch directory. Start `.bazel/bin/packages/wuhu-core/wuhu serve /tmp/wuhu106-proof/space --port 5573 --dev --web-app /tmp/wuhu106-proof/current-app`, then run `node /tmp/wuhu106-proof/proof.mjs`. Never use the live server ports. The CLI loads its app bundle once at startup; restart only this scratch process after updating the copied bundle.

`PROOF_ROOT`, `PROOF_PORT` and `SEMANTIC_FIXTURES` override the scratch paths/port. Chrome uses `ignoreHTTPSErrors: true`, page navigation waits for `load`, and the harness asserts `nextHopProtocol === "h2"`. `captures/*.png` and `proof.json` are review evidence, not repository fixtures; attach them to review and remove any transient image commit before landing.

## Assertions and visual comparison

Long source bodies stay complete in detail but compact in history, history scroll/focus survives drilling and active updates, and root text sizing at 150% is checked through computed font sizes and screenshots. Separate cases prove sends/trailing-work boundaries, raw fallback notices, reconnect retaining selected detail, generation-reset dismissal, and a bounded older-page prepend retaining the existing viewport anchor. Review regressions additionally exercise the exact receipt at G7/8 with a companion-only declaration at 7, followed by prepend folding that declaration beneath latest 9 while preserving the receipt viewport identity; a deliberately pending older page arriving during detail, followed by Back restoring the same visible history item offset and selected focus; a live committed inference extending the retained history segment; visible inspectable bookmarks after assistant/at a partial edge; and an empty stream placeholder showing Working while the session row is idle. Captures assert the expected inspection surface is actually open, rather than labeling a transient main-timeline screenshot as a history view.

Compare the timeline rail, quiet annotations, mixed row hierarchy, dialog width/rounding and detail payload hierarchy against the preserved transcript playground references. The surrounding product chrome remains unchanged. Iteration corrected dialog-width cascade, history-state alignment, Escape escaping to the compact sidebar, and a queued native-close event racing immediate modal reopening.

The CI `//packages/wuhu-web/app:test` target separately asserts the canonical shared semantic projections and every prefix, plus ten actual production-component HTML golden snapshots in `app/lib/transcript-snapshots/`. HTML goldens are deterministic markup assertions, **not pixel comparisons**. Locale-rendered time text is normalized while its exact machine-readable timestamp remains in the golden. Browser PNGs provide visual evidence and are inspected against the lab; no automated cross-environment pixel equality is claimed.

Self-signed scratch TLS can reject service-worker registration in Chrome. The harness records only that exact known warning separately and fails on all other page errors. This is not offline-shell proof or live model/executor verification.
