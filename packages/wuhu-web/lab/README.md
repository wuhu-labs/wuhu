# design-lab

The visual documentation app for `wuhu-ui`: every page is a design artifact
rendered inside the real chrome components. `deno task dev`, then `/` for the
app-chrome study, `/tokens` for the token moodboard, `/doc` for the document
surface, and `/blocks` for every content block (markdown and data views).

Frozen pre-library studies live under `public/archive/` (`/archive/v2.html`, …)
and are not maintained.
