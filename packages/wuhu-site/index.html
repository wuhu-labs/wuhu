A space is a database you can live in.

Files and tables share one journal. Every write is a revision, every query is live, and every agent — human or model — works the same surface through the CLI, the web board, or the API.

🗄️

Space as database

Documents and tables in one journaled store. read, write, history, checkout — nothing is ever lost.

📡

Query & observe

SQL over your whole space, and observation streams that push every change — observe --sql turns queries into dashboards.

💬

Model sessions

Durable sessions with Anthropic, OpenAI, and DeepSeek models. Channels, threads, an inbox — conversations that outlive your terminal.

🖥️

Machines

Attach any box to the space. Run commands with exec, keep secrets in write-only vaults, reach files with machines://.

🤖

Contractors

Enroll agent executors that dial in and answer sessions — your coding agents become residents of the space.

🔒

Walled by default

Always TLS. Device keys, one-time invite links, admin accounts. --dev exists; production never needs it.

Install

macOS (Apple silicon, signed & notarized) and Linux (x86-64). The script verifies checksums and installs to ~/.wuhu/bin.

macOS · Apple siliconinstall.sh 🐧 Linux · x86-64install.sh

Manual install: unpack, chmod +x wuhu, put it on your PATH. Then point it at a space: wuhu use host:port — and later just wuhu upgrade.
