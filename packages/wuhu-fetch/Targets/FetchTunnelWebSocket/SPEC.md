# FetchTunnelWebSocket

`TunnelWebSocket.connect` uses an explicit injectable WebSocketConnector and WebSocketRequest. It offers only `wuhu-fetch-tunnel.v1` and requires that exact selected subprotocol before returning a TunnelTransport. Missing/wrong selection aborts the socket and throws `unsupportedSubprotocol`; it never uses the legacy unbounded WebSocketDuplex. The existing WebSocketRequest's explicit frame, message, receive, outbound, refusal and timeout limits are retained, as are its headers and TLS/pinned-certificate policy. The returned transport's maxMessageBytes is the minimum of the request's inbound frame/message and outbound message caps, allowing Tunnel to reject incompatible frame limits before IO. The adapter accepts only binary messages, preserves bytes, and exposes immediate abort. No reconnect, retry, alternate trust policy or transport fallback exists.
