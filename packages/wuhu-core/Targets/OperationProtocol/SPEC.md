# OperationProtocol

Machine v2 is additive, process-free, and independent of transport direction. This module has no filesystem, process, machine-v1, server-store or identity dependency. `ComputerKindSchemas` describes exec, streaming read/find/grep and filesystem stat/list/write/mkdir/remove/move but implements none of their effects. Operation and request IDs are opaque UUIDs; machine/channel names are addressed strings. `Offset` encodes unsigned 64-bit positions as decimal strings, including beyond JavaScript's exact integer range, and rejects malformed/overflowing positions.

The Fetch address is `/machine/v2/machines/{machine}`. GET describes; POST `operations/{uuid}` starts once with `{kind,input}`; GET the operation polls state or `channel`, `after`, `limit`, `holdMs`; PUT `inputs/{channel}` accepts a contiguous prefix of `{offset,payload:{data|records},end}`; PUT `stop` carries `{reason}`. JSON `Data` is base64. Byte and record payloads are mutually exclusive; offsets count their declared unit. A GET with `terminalAck=<token>` plus committed channel offset acknowledges terminal retention. The envelope exposes execution verdict separately from output consumption. Completion requires a result, failure requires typed error evidence, and stopped requires a reason; runner envelopes cannot encode unknown.

Responses echo correlation and request headers and include `X-Wuhu-Agent-Instance`; all agent responses are JSON and `Cache-Control: no-store`. Errors are `{error:{code,message,operation?,details?}}`. Caller-deadline errors carry operation ID and `details.outcome=pending`, not a fabricated verdict. Server lease-silence errors carry `details.outcome=unknown`; definite runner `unknownOperation` is immediately conclusive. Description advertises protocol version, instance, start admission, limits and descriptors with JSON Schema 2020-12 input/result/channel schemas. Other schema dialects are unsupported, never routed to a different kind or stack.

Default bounds are a 60-second local lease, 20-second maximum poll hold, 128 KiB start envelope, 64 KiB result/record/poll payload, 256 KiB output and 64 KiB input windows, 32 active operations, 64 MiB machine buffer reservation, 4096 terminal receipts and 24-hour receipt retention. Each node injects its own monotonic clock; no peer timestamp is compared. Request cancellation is `requestCancelled`, with a separate cancelled trace event rather than requestDeadline. `OperationTrace` is a sanitized local-duration trace: addressed path and causal IDs, never bodies, query strings, authorization or secrets.

Desktop filesystem kinds add fileChanged (412), fileUnavailable and unsupportedDialect. storeUnavailable reports a missing/invalid encrypted durable-store configuration. grep.v1 advertises literal and ICU regex dialects. Patterns are at most 4096 UTF-8 bytes and compile during admission; invalid syntax yields invalidInput and unsupportedDialect rejects other dialects before filesystem effects. Lines are bounded by maxLineBytes (1...65536). Regex progress callbacks interrupt matching on stop, caller deadline or local lease expiry, including pathological backtracking; the common stopped verdict/reason and typed callerDeadline/requestCancelled contracts remain unchanged.

StartRequest.canonicalData normalizes the JSON wire representation and sorts object keys for durable input identity. Owner-key comparison and encrypted input digests use that form, so integral doubles and their decoded integer representation reuse one claim without a second dispatch.

`StartRequest.caller` is optional start metadata `{session, title, group}`: the server sets it from the calling session on every start a session caused (file tools, search, exec), and omits it when no session did. It is display-only, for the machine's audit, and never an authorization input. `canonicalData` leaves it out, so a replayed start whose session was renamed in between stays the same invocation. Old machines ignore the key; old servers never send it.
Computer supervisors additionally report spawnFailed, supervisorUnavailable, supervisorIdentityMismatch and invalidConfiguration as typed errors, never invented shell statuses or fallback paths.

Filesystem parity uses `stat.v1` (one entry result), `list.v1` (`entries` records and decimal count result), `write.v1` (`data` input and version result), `mkdir.v1`, `remove.v1` and `move.v1` (empty object results). Paths are absolute. Entry records carry name, kind, size, opaque token and mtime. Write start carries decimal bytes and lowercase SHA-256 digest in addition to path/optional ifMatch; bytes go only through the bounded input channel. The length and digest make a changed payload under an existing owner key an invocation conflict, not a silently reused write. Remove accepts ifMatch; move never overwrites a destination. These kinds use the same verbs, leases, receipts and terminal acknowledgements as every other kind.

Availability is optional on both sides, so old servers ignore it and old machines omit it. `KindDescriptor.summary` is an optional one-line description for agents. `MachineDescription.availability` maps kind names to `KindAvailability`: `{state: available}`, `{state: unavailable, reason}` (platform, edition, hardware, disabled, …), `{state: needsConsent}` or `{state: needsPermission, permission, permissionState}` (notDetermined, denied, restricted). It may name a kind the build knows but didn't link, which is then refused with its reason instead of unknownKind. `KindAvailability.refusal(kind:)` is the start refusal: kindUnavailable (409, details `{kind, reason}`, reason `needsConsent` for missing consent) or permissionDenied (403, details `{kind, permission, state}`). deviceLocked (503) is a run-time failure for protected data on a locked device. unknownKind (404) stays for kinds neither linked nor named. An unknown availability state fails decoding. `MachineDescription.upgrade` is likewise optional: a standalone box agent reports `{failed: {version, reason, at}}` after an automatic upgrade to `version` failed (`reason` one word, `at` ISO 8601), and drops it once it runs the target or the target changes. `KindAvailability.stopReason` names a revocation for operations already running: consentRevoked, permissionRevoked or kindUnavailable.

`OperationError.Code` is an open set: a raw-string struct whose wire form is the plain string, with a static constant per code this build defines (`known`, `isKnown`). A code a newer peer sends decodes as itself rather than failing the envelope, so an old server dispatching to a new machine surfaces kindUnavailable/permissionDenied (or any future code) intact instead of invalidResponse; switches over codes carry a `default`.
