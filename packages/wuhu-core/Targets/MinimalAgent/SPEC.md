# MinimalAgent

`MinimalAgent.run(request:log:workingDirectory:)` is the engine behind `wuhu agent`: one model, four tools, no space. It decodes the stdin request, builds a one-provider `ModelsDocument` from the request's `provider` entry and resolves `model` (`<provider>/<model>`) through `ProviderCatalog`, so dialects, prompt caching and the DeepSeek rule match the server's. The credential comes only from the request. Options are `maxTokens` = the model's `maxOutput` and its configured effort (`none` on an Anthropic endpoint turns thinking off).

The request is `{model, effort?, provider, credential: {apiKey} | {chatGPT: {accessToken, accountID}}, system, task, maxTurns, bashTimeoutSeconds}`. `maxTurns` (model calls in this run) and `bashTimeoutSeconds` are required and positive. Any decoding or catalog failure is `invalidRequest` before a model call.

Tools are `read`, `write`, `bash` and `complete`. Relative paths resolve against the working directory. `bash` runs `bash -c` in its own process group with `WUHU_TOKEN` and every variable carrying a masked secret removed from its environment, waits for it, and returns the exit status with the combined output; at the timeout the whole group is SIGKILLed and the result says so. `read` and `bash` results keep the first and last 16 KiB of anything past 32 KiB and name the bytes omitted.

The loop sends the transcript with the four tools, appends the reply and runs its calls in order. A reply calling `complete` with a string `result` ends the run with that result; other calls in that reply are answered "not run" and nothing executes. A reply without a tool call gets one reminder user turn; a second in a row is `noComplete`. Running out of `maxTurns` is `turnBudgetExhausted`. Provider failures are `inference`, never retried. The credential and the inherited `WUHU_TOKEN` are replaced by `***` in everything that leaves the agent: the task, each reply and its tool calls, each tool result, the final result and every error message, before any of it is logged, sent back to the model or printed. Messages are masked string by string, tool-call arguments as parsed JSON, never as encoded text.

On Linux the agent makes itself non-dumpable before it reads anything, so its shell cannot read the agent's `/proc/<pid>/environ` or memory; when that fails the run ends as `isolation` with the errno, before the request is read. The token is still in the environment of the agent's ancestors in the exec tree, readable by any process of the same user; masking is what keeps it out of the transcript.

`AgentLog.new(path)` creates a JSONL transcript (one WuhuAI `Message` per line, appended with `O_APPEND`) exclusively, refusing an existing file or symlink, and never follows a symlink when appending; `.resume(path)` loads one, answers each tool call it left unanswered with an `interrupted` error result instead of re-running it, adds the new task as a user turn and keeps appending. A malformed transcript is `transcript`.
