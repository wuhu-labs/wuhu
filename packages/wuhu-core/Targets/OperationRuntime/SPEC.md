# OperationRuntime

`OperationAgent` owns one addressed machine and an injected authorization decision per request. Multiple agents may share a transport via an ordinary routing Handler; neither the reducer nor the client binds liveness to a connection. Unknown machines/kinds/operations and invalid channel/offset/schema/capacity cases are typed failures. A kind is decoded and prepared before admission, registered through a single `AnyOperationKind` erasure, and run without any process or filesystem assumption. The kind must validate its domain constraints and cooperate with cancellation at effect boundaries; the runtime cannot preempt arbitrary noncooperative in-process code or manufacture a stopped verdict before it returns.

The owner runs `await agent.run()` in its lifecycle task group and calls `shutdown()` to finish that lifecycle. Starts enqueue bounded work; executions and lease maintenance are owned by a discarding task group. `leave()` disables starts and requests cancellation, retaining real terminal evidence/output. Describe answers `leaving` only after every operation is terminal, every output prefix is explicitly acknowledged, and every terminal token is acknowledged. Retention reclamation is not acknowledgement: pending departure IDs and a bounded lost-evidence flag prevent expired output/receipts, including receipts removed before leave began, from manufacturing a successful departure. A socket close, agent re-registration or discovery never acts as leave or operation renewal.

The production `OperationState` and `ChannelState` are the functional core used directly by the deterministic simulator. Every valid operation request renews only that operation. Lease expiry sets irreversible stop intent; later polls cannot revive it. A late start receives only its own local initial lease. Stop and terminal verdicts are immutable; a natural completion that wins a stop race remains completed. Kinds can publish immutable terminal evidence independently of finite output-tail draining; final offsets remain absent until each output ends. Kinds use writableBytes and availableInput for nonblocking pipe integration; a published terminal tail remains drainable under backpressure without waiting behind stop intent. hasRetainedOperations and inspect are lifecycle inspection only, never a poll or lease renewal. inspect returns retained metadata for authenticated supervisor identity discovery. Kind validation runs during preparation before admission. State polls/stop bypass channel backpressure.

Channels are bounded suspending handles, not unbounded producer streams. Poll JSON does not escape slashes; registration budgets terminal metadata plus the bounded result and worst-case byte/record wire payload against the shared 256 KiB aggregate response cap, and the Handler checks the encoded envelope before returning it. Output bytes split to bounded windows, records publish atomically up to their cap, and full windows suspend producers while control requests remain usable. A snapshot kind can coalesce its own bounded unpublished staging value before calling send; already-offset records cannot be replaced. Input writes accept only a contiguous prefix, preserve retained overlap identity, return accepted offsets/blocked, and make fully accepted duplicates no-ops. Input EOF is fixed at the accepted offset. Output polls reclaim only the explicitly acknowledged prefix, reject stale/ahead offsets, and never infer acknowledgement from terminal state. Admission reserves all live channel windows; an output channel frees its reservation only when it has ended and its retained payload is empty, including published finite tails. Snapshots expose optional bufferReservationBytes for a supervising registry; absent on old responders, accounting stays conservative. Retained terminal input remains charged even after every output has been consumed. Unpolled terminal payload expires after one lease; the small receipt remains 24 hours, capped at admission.

The finite receipt cache rejects duplicates while retained. At-most-once across arbitrary delayed duplicate POSTs beyond retention is not promised: the client consumes one durable dispatch permission and the transport must never replay start. Agent recovery of real execs belongs to the supervisor slice; this runtime never recreates an unknown operation.

Linux/macOS tests run the production Handler, registered no-process kinds, client, store and reducers with injected faults. The same test kinds compile in the iOS CI test lane. The test README maps named examples, seed sweeps and later-slice fault rows. Real pipes/process groups/supervisor recovery, filesystem faults, tunnel framing/authentication, SQLite, services and rollouts are explicitly not proven by these process-free simulations.

A kind can request an irreversible stopped verdict with `OperationCancellation.stop(reason:)`; it sets stop intent and throws cooperative cancellation. This is how filesystem scan caps end honestly without per-kind verbs. Typed OperationErrors raised during input preparation are preserved (for example unsupportedDialect), not flattened to invalidInput. Other decode failures remain invalidInput.
