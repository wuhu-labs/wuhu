# ClaudeStream

The stream reader decodes Claude Code JSONL frames, including `assistant` frames with message id, model, timestamp and provisional per-message usage. Missing or mistyped required assistant fields are malformed frames, not silently ignored data. `stream_event` envelopes emitted by `--include-partial-messages` remain `.other` frames; the inference collector reads their message lifecycle events without changing transcript decoding.

`ClaudeInferenceCalls.record` correlates `message_start`, `message_delta` and `message_stop` by message id, with an independent active message for each `parent_tool_use_id`. Usage in a message delta is cumulative, not additive: supplied input/cache/output fields replace earlier values; omitted fields retain earlier values. `record(_:at:)` receives the frame arrival time from the host. The first assistant timestamp and last assistant model are retained when an assistant arrives. Assistant block frames cannot overwrite final delta usage. At message stop, the collector emits exactly one completed call with the final usage, before any tool-result or turn boundary. An assistant frame arriving after message stop supplies the missing metadata and completes the call then. Replayed completed ids are ignored.

At result or process EOF, every unfinished stream yields one `cancelled` call with the reported input/cache counts and the last output delta, or null output if no delta reported it. A stopped stream without an assistant yields an `ok` call on drain. Both use the first frame arrival time as `at` and a null served model when assistant metadata never arrived. A stopped stream with no output delta has null output, never the provisional start/assistant count. Unreported token fields are null. For streams without partial-message events, the legacy assistant-only collector remains available: a different assistant id, user/tool-result frame, result, or EOF completes the pending assistant using its last usage. The production host enables partial messages and persists each completed call before forwarding any subsequent frame. Result-frame usage remains turn-level context information, never an inference row.

`Tests/Fixtures/partial-usage.jsonl` is a synthetic fixture in the Anthropic message-stream shape, not a live model capture. It covers per-block provisional usage, final updates to all four token counts, output-only deltas, cumulative replacement, and an assistant emitted after message stop. Additional tests cover cancelled partial rows, completed rows without assistant metadata, nullable usage, and first-arrival timestamp fallback. Existing captured fixtures are unchanged.
