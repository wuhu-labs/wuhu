# MainHub

`Hub` holds the session verbs against the real space store, provider credentials and machine contracts. Construction is inert: it opens no database and starts no tasks. The composition owner supplies an already-open `Space` and owns the Hub's lifetime.

Boot recovery consumes stale script owners directly from Space, once, and enqueues one notification per owner.

The agent's file tools (read, write, edit) run in the tool executor over main's HTTP API with the fold's access log as their guard; Hub touches files itself only to place a generated image and to read an attachment. The session verbs (send_message, request, report, create_session, manipulate_ui, machines, templates) are Hub methods the session gate calls as the session; the tools reach them only as API requests keyed by the tool call. For `observe` and `timer` Hub only checks the call (`arming`: the source, the schedule, the handler path, the name, and a query's baseline rows read as the subscriber) and the gate hands the `Arming` to the session's cell, which arms it; the subscription half of `cancel` goes to the cell alone. A call id still determines message, request and report identities. Session creation and device commands no longer replay recorded answers: kernel mutation jobs do not execute their effect twice.

MainHub contains no interpreter or loop dependency. SpaceServer composes a Hub with SessionTools and LoopCore. The TestDependencyKey-only `SessionEffects` client is explicitly injected where SessionExecution is composed; it carries creation, named-observer arm/cancel/list and post-template prompt invalidation into MainHub without a production dependency on LoopCore. Tests that create sessions compose the real execution through a test-only LoopCore dependency.

`Hub.armObserver(group, input)` validates terms, runs an observation query as the observer to pin its baseline, and arms `obs.<uuid>` or `timer.<uuid>`. Who may arm, cancel or list is the route's to admit. Its injected effect calls the group-and-name ObserverCell; there is no host subscription firing task or registry watcher. The space's `ObservationJob` mails SQL snapshots directly to their owners, which convert and throttle them. Handler execution and retries belong to LoopCore's observer cells and handler jobs.

Main owns machine exec records, not per-call jobs. `pendingArrivals` exposes queue urgency for the worker’s wait cut; `owedExecs` reads owed tool-call exec records, terminal or live, and their opaque worker specs. `openRequests` reads the requests the session is the task of that are still open; the `requests` table is the only record of what a session owes. The worker reads it when `compact(park: true)` decides whether to refuse, at the step-end nag, when a parked session schedules its park wake, and for a portable handoff, which keeps those requests' briefs; group switching reads it for its handoff too. The worker owns end settlement, acknowledgement, cancellation and adoption on mount. Generation heads remain snapshots and are not rewritten by exec completion.
